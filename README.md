# Ну, погоди! — Электроника

Ретро-аркада на TypeScript + React: волк ловит яйца, которые падают сверху. Чем дольше играешь, тем быстрее падают яйца и чаще они появляются.

## Запуск

```bash
npm i
npm run dev
```

Приложение откроется на [http://localhost:8080].

Остальные команды:

```bash
npm test        # юнит- и компонентные тесты (Vitest, jsdom)
npm run lint    # ESLint + Prettier
npm run typecheck
npm run build   # сборка в dist/
```

## Управление

- `←` / `→` или `A` / `D` — движение волка.
- `P`, `Esc` или `Пробел` — пауза и продолжение.
- Экранные кнопки слева и справа — мышь и touch (pointer events).
- Кнопка динамика — включение и выключение звука.
- Кнопка паузы — пауза, «Заново» и выход в меню.

## Правила

- На старте 3 жизни.
- Пойманное яйцо даёт +1 очко.
- Упавшее на землю яйцо отнимает жизнь.
- Когда жизни заканчиваются, показывается финальный счёт и рекорд.
- Рекорд хранится в `localStorage`.
- Каждые 12 секунд игра усложняется: растёт скорость падения и уменьшается интервал появления яиц.

## Архитектура

```text
src/
  game/          — чистая логика: конфиг, типы, состояние, физика, коллизии
  components/    — StartScreen, GameScreen, GameOverScreen, Hud, TouchControls
  hooks/         — useGameLoop (requestAnimationFrame)
  audio/         — SoundManager на Web Audio API
  utils/         — сохранение рекорда в localStorage
  styles/        — общие стили сцены и кнопок
  App.tsx        — переключение состояний start / playing / paused / gameover
```

Игровая логика не зависит от DOM и рендера: `src/game/logic.ts` экспортирует `createInitialState`, `startGame`, `spawnEgg`, `updateState`, `togglePause`, `resetGame`. Все настройки — в `src/game/config.ts` (размеры поля, жизни, скорость волка, скорость и частота падения, ускорение, ключ localStorage).

## Тесты

- `src/game/logic.test.ts` — стартовое состояние, поимка и пропуск яиц, gameover, границы поля, пауза, сброс, спавн и рост сложности.
- `src/App.test.tsx` — стартовый экран, переход в игру, пауза/продолжение, финальный счёт и рекорд на экране проигрыша.

Все ассеты (волк, курица, фон, яйца, иконки) нарисованы CSS и inline-SVG. Звуки синтезируются через Web Audio API; аудиоконтекст создаётся после первого действия пользователя (кнопка «Играть»), чтобы не попасть под блокировку автозапуска.
